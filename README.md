# 🚀 Tebogo Mathaba | Interactive Developer Portfolio

A futuristic, highly interactive, and fully responsive personal portfolio website showcasing my skills in Software Engineering, Data Analysis, and Full-Stack Development. 

Designed with a modern "Cyber/Glassmorphism" aesthetic, this portfolio goes beyond a static document by integrating interactive micro-animations and a functioning simulated command-line interface.

## ✨ Key Features

- **🧠 Neural Network Background:** A dynamic, interactive HTML5 Canvas background where particles connect to each other and react to screen resizing.
- **💻 Interactive Hacker Terminal:** A built-in, functional command-line interface where users can type commands (e.g., `help`, `about`, `stack`, `contact`) to interact with my data.
- **🌀 3D Card Tilt Effect:** Project and skill cards tilt in 3D space relative to the user's mouse position for a premium, tactile feel.
- **📟 Cyber Glitch Typography:** CSS-only glitch animations on the main hero text.
- **🖱️ Custom UI/UX:** Features a custom target-reticle cursor, scroll progress bar, and floating action buttons.
- **📱 Fully Responsive:** Carefully structured to look pristine on 4K desktop monitors, tablets, and mobile devices.
- **📊 Live GitHub Activity:** Integrates a dynamic chart of my latest GitHub commits.

## 🛠️ Built With

This project was built from scratch using pure frontend technologies—no heavy frameworks or external libraries required:
- **HTML5** (Semantic structuring)
- **CSS3** (Variables, Grid, Flexbox, Keyframe Animations, Glassmorphism)
- **Vanilla JavaScript** (Canvas API, DOM Manipulation, Intersection Observers)
- **FontAwesome** (Icons)
- **Google Fonts** (Outfit & Space Grotesk)
